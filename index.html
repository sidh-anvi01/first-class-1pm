The first push

Four steps to publish your project.

01 / PREPARE01

Initialize Git

Start tracking the project in this folder.

git init
02 / SAVE02

Commit your files

Stage your work, then save a snapshot.

git add .
git commit -m "Initial commit"
03 / CONNECT03

Set up GitHub

Create a remote repo and link it here.

git branch -M main
git remote add origin <url>
04 / PUBLISH04

Push it up

Publish the main branch for the first time.

git push -u origin main
